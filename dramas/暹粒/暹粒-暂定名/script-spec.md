# 暹粒（暂定名） 剧本创作规格

## 目标
- 交付类型：竖屏短剧
- 集数/段落数：36
- 单集/单段时长：90–120 秒/集
- 原素材：原创创意（穿越题材）

## 用户要求
为确认后的短剧项目执行《暹粒》（暂定名，确认时可改）。 定位：原创穿越爽感竖屏短剧。题材：历史穿越 + 战争逆袭 + 地名源起。受众情绪：代入感、被轻视后翻盘、以弱胜强反杀、家国热血、“我改变历史、后世因此铭记我”的闭环爽点。 剧情主线（依据用户创意，不改因果脊柱）：现代柬埔寨大学生穿越回古代高棉，落入暹罗（阿瑜陀耶王朝）大军压境的危局，凭借现代军事常识与组织方法，从被轻视的外来者成长为军中谋主，帮助高棉王国击败暹罗入侵、收复失地；战后高棉为纪念这场胜利，将此地命名为“暹粒”（意为“暹罗被击败之地”），并以主人公留下的痕迹完成“暹粒名字由来”的闭环。 史实处理边界（硬约束，按史实）： - 敌方一律称“暹罗/暹”，全剧不出现“泰国”等现代国家称谓，不出现现代民族主义口号式台词。 - 故事设定在高棉吴哥衰落后、暹罗与柬埔寨反复争夺今暹粒一带的史实框架内。正史有明确记载的国王、都城、年号与重大战役不得虚构或篡改；该地名得名的具体过程本身属口述源流，史载空白处允许用与时代一致的王室结构与虚构配角填补。 - 年代落点默认采用“暹罗入侵、柬埔寨一方反击获胜、围绕今暹粒地区归属”的时代窗口（工作值，可在确认时改）；执行时所有年代、人物与战役细节须按可考正史校准，不确定的史实不硬造。 - 金手指限于时代内可行：后世战术认知（伏击、粮道、城防工事、围城与诈术、象战与战船编组、按该时代东南亚实际具备水平的火器运用）、组织动员方法（纪律、奖惩、旗号、侦查）、预知历史结果的判断优势。禁止超时代科技与直接移植现代政治制度、口号。 - 称谓与语言：宫廷、军职、地名按该时代相符的称呼体系处理，不出现现代行政区划与意识形态词汇。 主角设定底线：现代柬埔寨大学生，保留柬埔寨人身份认同与对“暹粒”的地缘情感；具体专业与背景为可自由设定空白。 形式规格：竖屏短剧。默认工作版本 36 集、单集约 90–120 秒（确认时可改）。叙事按爽感短剧结构：第 1 集强冲突开场并完成穿越交代，不铺垫世界观；每集必须有完整戏剧动作（目标—阻力—转折—后果）并以结尾钩子/反转/升级收住，不写剧情摘要替代场景。剧本按可演场景输出 Markdown：动作行只含可演可视内容，内心戏转为行为、对白、道具、证据或可见反应；对白须推进冲突、关系、信息或情绪，不用来解说设定。 成本档位（默认工作值，可改）：如无预算要求，战争戏按低成本可拍处理——以局部战术奇观（象阵冲阵、夜袭火攻、水寨、城防对峙）与近身对抗为主，避免大规模群演与 CGI 依赖。 交付物：完整分集剧本（Markdown），附分集梗概表、人物表与主要场景表，路径默认 dramas/暹粒/（可改）。

补充要求：
竖屏爽感短剧：36 集（可调）、单集约 90–120 秒（可调）、每集完整戏剧动作加结尾钩子；按史实边界：敌方称暹罗/暹，不出现泰国等现代称谓，正史明确记载的人物与战役不虚构篡改，地名得名过程属口述源流可合理填补；金手指限于时代内可行的战术、工程、组织与象战/水战运用，禁超时代科技；对白推进冲突不解说设定；战争戏默认低成本可拍（局部战术奇观+近身对抗，可改为大制作）；输出完整可演剧本与分集梗概、人物表、场景表，路径默认 dramas/暹粒/。
