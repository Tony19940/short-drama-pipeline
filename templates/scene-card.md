## 空间平面 `geo_zh`

中文一段，抄进 `sets.json` 该场 `geo_zh`；5.2 原样前置到同场每镜提示词，逐字相同。写六件事：

1. 地标：房间几个面，门 / 窗 / 柜 / 锚点物各在哪面墙
2. 画左 / 画右：主机位下谁在左、谁在右，锚点物在哪一侧
3. 米数：人和人、人和锚点物、人和镜头大约几米
4. 机位侧：机位全在轴的哪一侧
5. 永不过的线：哪条线（人物连线 / 门框 / 桌边）任何机位都不越过
6. 光从哪来：主光方向、光源是什么、颜色

同一节旁边写 `sound_bed_zh`：这场的环境底噪一句（「车间缝纫机运转声」「河岸水声与晚风」），`audio_block` 的「只有环境声：…」从这里读；不写就按 id 关键词套默认。

例：`长条车间，纵深 12 米。画左一排缝纫台，画右墙上挂工牌板（锚点物），尽头是铁门。春安在画右工牌板下，琳在画左过道，两人相距约 3 米。机位全在缝纫台这一侧，永不越过两人连线。主光从画右高窗进来，冷白日光，顶灯管补一点绿。`
