# 配音导演（借鉴配音导演 skill）

声音演员要的是意图，不是“这一句往上扬”。中文工作轨的对白现在由 Seedance 原声唇同步出（`speech_mode=seedance_native`），本页规则给两处用：写进提示词的**声线卡**，和原声不可用时的**重录单**。

- 口述 / 心里 / 旁白 / 出场简介 四类，写在 line/caption，不进 video_prompt；对白只进 `audio_block` 引号里
- 好念：一句一个意思，长度配得上镜头秒数
- 每条写：谁说、情绪意图、切在哪、为什么
- 重录单写时间、现在的问题、希望改成什么、故事原因。只有原声缺 / 错词 / H3 fallback 镜才重录
- 工作轨中文；成片高棉语另走 Gate F（Seedance 没有高棉语）

## 声线卡 `voice_card`

每个有台词的人物一张，1–2 句，写在 `01-bible/CHARACTERS.md` 该人一节的 `- **声音卡**：` 行（真源；`.pipeline/voice_cards.json` 是机器抄本，`assets[].voice_card` 抄同一句），5.2 **逐字**贴进每条 `audio_block` 的最前面，全集不改字。

写什么：音高（低 / 中 / 偏高）、音色（沙、亮、闷、鼻音）、节奏（慢、句尾往下压、爱停顿）、口音 / 用词习惯、说话时的身体习惯。

不写什么：情绪形容词（冷、凶、委屈）、年龄、「像某演员」。情绪由这一镜的台词语气和 `acting` 给。

例：

- 春安：`低而沙的中年男声，语速慢，句尾往下压，几乎不拖长音；说话时先吸一口气再开口。`
- 琳：`中音偏亮，口齿清，节奏快，句中不停顿；生气时反而更轻更慢。`

`audio_block` 里的顺序：声线卡 → 「引号台词」+ 语种 + 语气（怎么说，不是什么心情）→ 只说这一句 → 不说话的人嘴闭着 → 只有环境声，无音乐，无字幕。说话时的动作和表情（肌肉）写在紧跟的【表演】句里，不进 `audio_block`。
