# 藏账 / 缝进马甲
tags: 藏账、账本、账页、缝、马甲、针线、夹层、撕下、塞进、藏起、U盘

## 机位

手的戏。两个机位都对着手，脸只在开头和结尾各一眼。

```
   门●（有人会来）
        ●藏账的人（背对门，面向画右）        ─ 轴：门画左，桌画右
      ▲A(50 侧·人+桌+门口同框)
              ▲B(85 特·手/针/账页，俯)
```

## 先给什么

先东西（账页、U 盘）和藏处（马甲夹层）同框，再手开始动，再门外的动静，最后手加快。脸最后一眼。

## 景别序列与秒数

- medium · 3–4 秒 · 桌上账本，马甲摊开，门在背景
- insert · 3–4 秒 · 撕下 / 抽出，对折
- insert · 3–5 秒 · 针线穿过夹层，手稳
- medium · 2–3 秒 · 门外脚步声，手停一下（无台词）
- insert · 2–3 秒 · 最后一针，线咬断
- close · 2–3 秒 · 抬头，脸没事

## 何时切特写与反应

手一开始就切特写，全程留在手上。脚步声那一镜回中景，让门口进画。反应只用「手停」。

## 剪在哪

剪在线咬断、手停住、马甲合上的瞬间。

## 绝对不要

账页上出现可读汉字；一镜里手从撕到缝完；针线动作超过 5 秒不切；抬头那镜给门口的人正脸（留给下一场）。
