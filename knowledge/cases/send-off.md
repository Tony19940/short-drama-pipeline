# 送走
tags: 送走、抬走、上车、赶走、不走、铜铃、拓片、上路、离开

## 机位

门口全景 + 拒绝者特写 + 上路插入。

```
   屋内●拒绝者      门│      ●被送走者→→ 路
        ▲B(85 特)   │   ▲A(35 门口全景)
                    │        ▲C(50 insert 物件/车轮)
```

## 先给什么

先门口的全景：谁在门里、谁要出去。再拒绝者的脸。最后动势出画。

## 景别序列与秒数

- full/master · 3–5 秒 · 门口两边站位
- close · 2–3 秒 · 拒绝者一句，短、狠
- full · 3–5 秒 · 抬走 / 上车，带动势出画
- insert · 2–3 秒 · 铜铃、拓片、车轮收尾

## 何时切特写与反应

拒绝的那句切特写，说完立刻切走。被送走者的反应用全景里的身体给，不另给脸。

## 剪在哪

剪在身体被抬起或车轮滚动时，不剪在已经坐定。

## 绝对不要

「我不走」配 8 秒冻住；送走之后再回头给一张告别海报；门里门外一镜跨完。
