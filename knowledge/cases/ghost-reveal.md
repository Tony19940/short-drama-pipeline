# 魂魄首次出场
tags: 魂魄、波帕、半透明、灯管、胸口、透过、抹灰、工牌、影子、离地、发光、身后

## 机位

3 个 + insert。人物机位在活人这边，魂魄永远出现在她身后或侧后，第一次不给正面全身。

```
   铁皮柜●
        琳●←(背后)●波帕          ─ 轴：柜在画左，门在画右
      ▲C(85 特·脸)   ▲B(50 越肩·灯管透胸)
              ▲A(35 半身)
```

## 先给什么

先局部，再反应，再全身。顺序不可倒：
1. 灯管的光从「什么东西」的胸口透过来（局部，不见脸）
2. 琳的反应：退、撞柜、扫把落地
3. 半身：白衬衫、淡冷白光、脚不在画里
4. 最后才是全身，且盖脚——脚离地一掌，画面下缘切在小腿

## 景别序列与秒数

- insert · 3–4 秒 · 工牌抹灰：姓名出来（证据，读得清）
- close · 2–3 秒 · 琳的脸，还没看见
- otc/medium · 3–4 秒 · 同侧过肩（不是整背影）：画左只留琳的肩和发网后脑，她仍低头看牌；灯管从身后胸口透过来，暖金边缘。父图用上一镜正脸首帧。
- close 反应 · 2–3 秒 · 退撞柜门，扫把掉
- medium · 4–5 秒 · 波帕半身开口：「你看得见我」
- full · 3–4 秒 · 全身，盖脚，地上没有影子

## 何时切特写与反应

「透过来」那一镜后必须立刻切反应，不许在魂魄身上停超过 4 秒。第一句台词在半身镜，不在全身镜。

## 剪在哪

剪在灰被抹开的一下、扫把落地的一下、琳抬头的一下。全身镜从身体已经在画里开始，不做「浮现」动画。

## 绝对不要

先全身再局部；给脚、给鞋；血、伤口、恐怖片式尖叫；实体人皮质感；第二个光源抢灯管；波帕出场那镜右肩后留白被塞满。
