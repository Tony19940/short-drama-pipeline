# 烧退路 / 出逃
tags: 出逃、逃、点火、烧、破门、追、退路、跑、冲出

## 机位

地理全景 + 点火/破门特写，可选人群反应。

```
   退路────────────●门/火          ─ 轴：逃向画右
          ▲B(50 特·手/火)
   主角●→→
  ▲A(24 全景)   ▲C(50 人群反应，可选)
```

## 先给什么

0–3 秒内看见冲突发生（火起、门被撞），不要风景空镜。再给谁在逃、往哪逃。

## 景别序列与秒数

- wide · 3–6 秒 · 地理与逃向
- insert/close · 2–3 秒 · 点火 / 破门那一下
- full/follow · 3–5 秒 · 人动，方向不变
- close 反应 · 2 秒 · 追的人或人群一眼

## 何时切特写与反应

火起或门开的瞬间切特写；人群反应只给一眼，不做群像。

## 剪在哪

动作没收完就切：脚离地、门半开、火刚窜。全景可稍长，特写仍短。

## 绝对不要

航拍、人海、换城；一镜里既在门内又在门外；逃向中途翻左右。
