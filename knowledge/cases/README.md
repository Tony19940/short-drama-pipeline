# 场型卡

拉片博主的口播是教材。拆镜 Agent 只读这里蒸馏过的半页卡。
一场只用最像的 1–2 张（`knowledge.cases_for` 按 `tags` 命中挑），禁止把整段讲解灌进提示词。
场戏分析岗在场卡 `case_cards[]` 里点名；拆镜岗读全文，照它的刀法，不照它的剧情。

## 卡的格式

每张卡一个文件 `knowledge/cases/<id>.md`，结构固定，机器按行读：

```
# 标题                       ← 第一行，场型名
tags: 词、词、词             ← 第二行。写剧本里会出现的中文词（工牌、魂魄、签字…），机器靶这些词匹配场次

## 机位                      ← 2–3 个机位 + insert，含 ASCII 顶视图：●人物 ▲机位 ─轴
## 先给什么                  ← 观众被允许看见东西的顺序
## 景别序列与秒数            ← 一行一镜：景别 · 秒 · 干什么
## 何时切特写与反应          ← 特写在哪个瞬间；对白后的反应给谁、几秒
## 剪在哪                    ← 剪在动作中途的哪一下
## 绝对不要                  ← 这种场最常见的错
```

规矩：

- `tags` 用剧本正文会写的词，不用抽象词（写「签字、笔帽」不写「压迫」）。单字词少用，会乱命中。
- 顶视图只画轴和机位，不画布景。机位标焦段，特写机位标「特」。
- 秒数是范围，不是命令。纸面走桶：反应 1.2–2.0，插入 1.5–2.5，对白 2.5–4.5，建立 3–5，长镜 5–8。能力档最短几秒只约束渲染，不把纸面垫到 4s。
- 每张卡半页以内。讲不完的是两张卡。
