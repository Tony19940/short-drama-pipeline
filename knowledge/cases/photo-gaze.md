# 合影凝视 / 旧照认人
tags: 合影、旧照、照片、相框、凝视、认出、盯着、指着、那张脸、年份

## 机位

照片是证据，先让观众读清；凝视的人是反应。两个机位一前一后。

```
   墙│●照片
     │  ▲B(85 特·照片，正对)
     │        ●看照片的人
     │      ▲A(50 侧后·人+照片同框)
     │  ▲C(85 特·脸)
```

## 先给什么

先照片里的「不对」（那张脸、年份、站位），再凝视者的眼。魂魄在照片里时，先照片里的她，再身边的她。

## 景别序列与秒数

- medium · 3–4 秒 · 人走近墙/桌，照片在画里但读不清
- insert · 3–4 秒 · 照片正对，能认出脸，手指停在某一张脸上
- close 反应 · 2–4 秒 · 凝视，眼不动
- medium · 2–3 秒 · 抬头，看向身边（认出的对象）

## 何时切特写与反应

手指停住切照片特写；照片看清后才切脸。认出的那一眼无台词。

## 剪在哪

剪在手指停住、目光从照片抬起的瞬间。

## 绝对不要

照片放进 wide；照片里出现汉字标牌；相框反光盖住脸；凝视超过 5 秒；照片内容用旁白说。
