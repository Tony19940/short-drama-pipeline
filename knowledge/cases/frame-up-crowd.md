# 栽赃围观逼签
tags: 栽赃、围观、逼签、人赃、清洁车、布、吊牌、离职书、签字、围人、女工们、当众

## 机位

围观是墙，不是人海。2 个人物机位 + 1 个「墙」机位 + insert。

```
        女工们●●●●●（半圆，背景，虚）
   春安●────────────●琳                ─ 轴：春安画右，琳画左
      ▲B(50 越肩·从琳肩看春安)   ▲C(85 特·琳/物)
              ▲A(35 半圆全景)
```

## 先给什么

先赃物从车里出来（物），再围观的脸（墙），再被指的人（琳）。逼签时先笔和纸，再她的手不动。

## 景别序列与秒数

- full/master · 4–5 秒 · 半圆围人，车在中间
- insert · 2–3 秒 · 藏青布拖出，吊牌还在
- otc · 3–4 秒 · 春安一句：「今天签字，今天走」
- close 反应 · 2–3 秒 · 琳想说，话散了
- insert · 2–3 秒 · 离职书摊开，笔帽拧开
- medium · 3–4 秒 · 全场等她；她的手在桌边不动

## 何时切特写与反应

赃物一出切围观一眼（一镜，2 秒，不做群像轮切）。每句指控后给琳一眼无台词反应。逼签那句之后不再给春安，只给纸、笔、手。

## 剪在哪

剪在布甩到地上那一下、笔帽拧开那一下。不剪在春安说完、也不剪在琳开口。

## 绝对不要

围观者一人一个反应镜；琳辩解说成整段；春安占最紧景别（最紧留给琳或笔）；一镜里既有车底层又有桌面。
