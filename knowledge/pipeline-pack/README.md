# 短剧流水线 Agent 落地包

给本地 Codex / Cursor 改造现有流水线用。不要脱离本包另发明环节。

## 用什么

| 文件 | 给谁 | 干什么 |
|---|---|---|
| `改造总令.md` | Codex / Cursor | 第一条改造指令，先贴这个 |
| `交接字段表.md` | Codex / Cursor | 每岗输入输出字段，改代码时按这个对齐 |
| `prompts/` | 每个 Agent 的系统提示词 | 创建或替换各环节的 system prompt |
| `../短剧流水线_Agent岗位说明书.md` | 人 + 编码 Agent | 完整规则和澄清，有争议时以它为准 |

## 推荐改造顺序

1. 把本目录和岗位说明书放进现有仓库
2. 打开 Codex / Cursor，先贴 `改造总令.md`
3. 让它先画出「现有模块 → 本包 11 岗」对照表，你确认后再改代码
4. 按 `交接字段表.md` 改各岗输入输出
5. 把 `prompts/` 里对应正文贴进各 Agent / Skill

## 项目 Recipe 目录（过程必须能打开看）

```text
project/
  01_小说/
  02_编剧/
  03_资产/
  04_分镜设计/
  05_1_说明书/
  05_2_生成包/
  06_1_关键帧/
  06_2_视频/
  07_声音/
  08_剪辑/
  _continuity_bible.json
  _failure_log.json
```

每岗只往自己的文件夹写字段表规定的文件。  
`_continuity_bible.json` 由分镜设计创建，5.1 / 5.2 / 6.1 / 6.2 只继承。  
生成调用前必须能打开 05_2_生成包 里对应 shot 的文件。
