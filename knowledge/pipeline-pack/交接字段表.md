# 交接字段表

每岗只收表内输入，只交表内输出。缺必填项 = 未完成，统筹打回。  
字段名固定，下游按字段取值，不要解析散文。

通用头（除统筹外，每份产出都带）：

```text
project_id
episode_no          可空（小说岗可空）
scene_id            可空
shot_id             可空
agent               本岗名称
version
status              draft | ready | rejected
reject_reason       status=rejected 时必填
```

---

## 0. 制片统筹

**输入** `from_agent` `artifact` `required_fields_ok` `gates`

**输出**

| 字段 | 必填 | 说明 |
|---|---|---|
| decision | 是 | pass / reject |
| next_agent | decision=pass 时是 | 下一岗名称 |
| reject_to | decision=reject 时是 | 打回哪一岗 |
| reject_reason | reject 时是 | 缺什么或违反哪条 |
| gates.storyboard_approved | 进 6.2 前是 | 关键帧是否过审 |
| gates.video_approved | 进剪辑前是 | 视频是否过审 |
| gates.package_confirmed | 进 6.1 前是 | 生成包是否经人确认 |
| gates.mute_test | 编剧/分镜交岗时是 | 静音后能否感到变化 |
| failure_ticket.type | reject 时是 | 失败类型 |
| failure_ticket.send_back_to | reject 时是 | 打回哪岗 |
| failure_ticket.evidence | reject 时是 | 证据 |

硬闸：`gates.storyboard_approved != true` 不得派 6.2；`gates.video_approved != true` 不得派剪辑。  
`gates.package_confirmed != true` 不得调用生图或生视频。  
`gates.mute_test != pass` 打回编剧或分镜设计，不打回视频模型。

## 3. 视觉资产

**输入** `series_bible` `scenes[]`（人物、服装状态、场景、道具）

**输出 `assets[]`**

| 字段 | 必填 | 说明 |
|---|---|---|
| asset_id | 是 | 如 CHAR_SHENQING_COAT_V1 |
| type | 是 | character / costume_state / location / prop / creature / style |
| name | 是 | |
| binds_to | 是 | character_name / location_id / prop_name |
| file | 是 | 已生成的图片路径 |
| what_it_locks | 是 | 身份/服装/空间/道具，不是某镜构图 |
| version | 是 | |
| lock_card | 是 | 按类型从字段库摘出的锁定项；每项含 value 与 source |
| lock_card[].key | 是 | 如 hair_length, coat_color, time_of_day |
| lock_card[].value | 否 | 剧本未写则空 |
| lock_card[].source | 是 | script / inferred_empty |
| image_prompt | 是 | 只由 source=script 的字段生成 |
| quality_layer | 人物/服装必填 | 默认 anti_plastic。不是设定，是质量锁 |

style 资产必须含 `anti_plastic` 文本块，供人物 image_prompt 追加。  
anti_plastic 不得写入 lock_card 身份字段。

`lock_card` 按类型启用，不是全量必填：

- character / costume_state：人物枝（脸、身体、服装）。表情和姿势只许中性。
- creature：生物枝，仅剧本有生物时。
- prop：物品枝。
- location：场景枝 + 时间枝（年代、季节、时刻）。日夜是场景版本，不是人物版本。
- style：全剧画风与光线气质。

不准输出 shot 构图图。不准发明 bible 里没有的角色和地点。  
`source=inferred_empty` 的字段不得写进 image_prompt，不得画进图。

## 4. 分镜设计（镜头表，`schema: shot-table-v2`）

**输入** 本集完整剧本正文 + 编剧岗全部 `scenes[]`（含 `scene_job / start_state / end_state`）+ `sets[]` 轴 + `LOOK.md` + 目标模型能力档（`director/video_profiles.py`）。

**调用** 一次 `header`（表头：视点、每场左右锁、连戏圣经、每场镜数/秒数/节拍计划），然后一场一次 `scene`。每场单独过机器校验，不过就带着错误清单重来一次。

**输出 `shot_list`**

| 字段 | 必填 | 说明 |
|---|---|---|
| schema | 是 | `shot-table-v2` |
| target_model | 是 | 设计时对着哪份能力档 |
| whose_pov | 是 | 全集主视点 |
| left_right_lock | 是 | 对象，键 `scene_id`，值一句话：谁左谁右、河/门/对岸在哪、运动朝哪 |
| continuity_bible.eyeline / wardrobe | 是 | 每场谁看什么；谁穿什么、什么时候变 |
| continuity_bible.day_night | 是 | 对象，键 `scene_id` |
| continuity_bible.props[] | 是 | `{name, first_scene, last_scene, note, assets[], aliases[], attached_to}`。last_scene 之后再出现即穿帮。`assets` 是资产 `binds_to`（一件道具的两种状态写两个），`aliases` 是文案里会怎么叫它，`attached_to` 是随身在谁身上 |
| continuity_bible.cast_assets | 否 | 对象，编剧 cast id → 资产 `binds_to`，只在两边名字对不上时写（如 `khmer_patrol → patrol`） |
| continuity_bible.evidence[] | 否 | `{what, scene_id}`。观众必须看清的证据，由某一镜的 `evidence[]` 认领，且不许在 wide |
| scene_plan[] | 是 | `{scene_id, target_shots, target_sec, beats[]}` |
| total_sec | 自动 | 各镜 `duration_sec` 相加 |
| shots[].shot_id / scene_id / location_id | 是 | `SH001` 全集连续；地点必须等于编剧场的 `location_id` |
| shots[].beat / shot_job / coverage_type | 是 | coverage 加 `pov / follow` |
| shots[].scale / angle / height / lens | 是 | wide/full/medium/close/otc/insert/pov；eye/high/low；`24mm`–`85mm` |
| shots[].move_type / move_reason | 是 | 默认 static；动要理由；只能选能力档 `allowed_moves` |
| shots[].left / right / eyeline | 是 | 同场同一对象不许左右翻 |
| shots[].one_action | 是 | 一个主动作，一镜一地点 |
| shots[].internal_cuts[] | 否 | `{at_sec, scale, one_action}`；只在能力档允许时，数量 ≤ `max_internal_cuts` |
| shots[].duration_sec | 是 | 整数；≥ 2 + 1.5×(分句−1) + Σ(字数÷4 + 0.8)；≤ 能力档上限；低于下限只警告 |
| shots[].dialogue_ref[] | 是 | `{character, line}` 原句；≤ 2 句；全场每句台词必须落到且只落到一镜 |
| shots[].dialogue_delivery | 是 | none / post / on_camera（on_camera 需能力档 `native_dialogue_audio`） |
| shots[].key_sfx[] / light | 否 | `light = {day_night, key_dir, quality, color}` |
| shots[].in_from / out_to | 是 | |
| shots[].evidence[] | 否 | 认领表头 evidence.what |
| shots[].visual_turn / hardest | 否 | |
| shots[].state | 是（一镜有则全表必有） | 这一镜的世界状态：`characters{cast_id: {costume, binding, bound_with, carrying[], in_frame}}`、`props[]`（在场的固定道具，资产 `binds_to`）、`location`（空镜变体，如 `ancient-shoal-night`）、`note`（一行给出图看的连戏句：穿什么、怎么绑、什么必须在/不在）。`binding` ∈ none / wrists_front / wrists_behind / pillar / snared / held；不是 none 就必须写 `bound_with` |
| shots[].state_changes[] | 变了才写 | 相对上一镜谁的什么变了，形如 `sokha.binding`、`sokha.costume`、`sokha.carrying`。没声明就变 = 校验 error |
| visible_change_without_dialogue | 是 | pass |
| dropped_shots[] / design_steps_done | 否 / 自动 | |

不准带：prompt、video_prompt、image_prompt、motion_prompt、asset_id、image_file。  
机器校验（`director/shot_table.py::validate_shot_table`）另查：紧景别不装远处内容、一镜不跨两个 set、同场同人同景别同左右不连排、道具消失后不再出现、证据镜不在 wide、运镜不在 LOOK 禁止项里。  
状态机（`validate_state_chain`）按镜序继承每个人物的 costume / binding / bound_with / carrying：没在 `state_changes` 声明就变是 error；`props` / `carrying` / `bound_with` 落在 bible 场跨度之外是 error；文案点了名却不在 `state.characters` 里是 warning；整张表没 state 只给一条 warning，有一镜有就全表必须有。  
生成包（5.2）的 `asset_refs`、`costume_state_id`、`binding` 直接从 `state` 查表得出，不再从文案撞关键词；`note` 原句进 `image_prompt`（「连戏必须照做：…」）和 `motion_prompt`（「连戏不变：…」）。紧景别（close / otc / insert / pov）里随身道具只有文案点名才进参考图，否则只留在 `note` 里。

**人审表** 校验通过后自动渲染 `03-storyboard/shot-list.draft.md`；人接受后再改名为正式 `shot-list.md`。

## 5. 分镜说明书（5.1）

`shot-table-v2` 的 `shot_specs.json` 由 `compile_specs_from_shot_table` 从镜头表**直接投影**，不再调模型，也不再猜缺字段。下面的 7 组只对旧 schema 的模型产出有效。

**输入** `shot_list` + 该场 `scene`

**输出 `shot_specs[]`，每颗 7 组全填**

| 组 | 字段 | 必填 |
|---|---|---|
| 1 内容 | subject, action_now, dialogue_line | 是。dialogue_line 必须等于编剧原句或空 |
| 2 机位几何 | shot_size, angle, height, focal_length, aspect_ratio | 是 |
| 3 运动 | move_type, move_detail, move_reason, intensity | 是。对话近景默认 static，intensity=0。禁止空泛词如电影感 |
| 4 调度 | left, right, eyeline, body_facing, hands, props | 是 |
| 5 光线 | day_night, key_light_dir, quality, color_mood | 是 |
| 6 时间声音 | duration_sec, dialogue_start_sec, key_sfx | 是 |
| 7 衔接 | axis_side, in_from, out_to, costume_state_id, location_state_id | 是 |

`aspect_ratio` 短剧默认 `9:16`。  
不准带：prompt、asset_id、keyframe_file。

## 7. 关键帧（6.1）

**输入** `gen_package` + 对应 `assets[].file`

**输出 `keyframes`**

| 字段 | 必填 | 说明 |
|---|---|---|
| shot_id | 是 | |
| first_frame_file | 是 | 本岗生成 |
| last_frame_file | keyframe_plan=first_last 时是 | 应改自首帧 |
| qc.status | 是 | pass / fail |
| qc.face | 是 | pass / fail |
| qc.costume | 是 | |
| qc.location | 是 | |
| qc.left_right | 是 | |
| qc.composition | 是 | |
| qc.aspect_ratio | 是 | |
| qc.plastic_face | 近景/特写是 | pass / fail / n/a |
| qc.anatomy | 近景/特写是 | 手、关节、重心、肩颈是否像人。pass / fail / n/a |
| qc.light_matches_spec | 是 | 不得用柔光覆盖 5.1 规定的光位 |
| qc.state_match | 是 | 帧对得上镜头表 `state.note`：服装状态、绑法（身前/身后/柱上）、该在的道具在、不该在的不在 |
| qc.out_to_readable | keyframe_plan=first_last 时是 | 陌生人对着首尾两帧能不能看出 `out_to` 那件事变了 |
| qc.notes | 有意见就写 | |
| qc.waived_by | notes 非空且 status=pass 时是 | 放过这个 nit 的人名。没有人名，nit 就是 fail |
| reviewed_by（文件级） | 是 | 过图的人名。Agent 不得代签 |
| scene_strip_id | 否 | 若按场成组出关键帧 |

输入要求 `gen_package.confirmed == true`。  
任一项 fail → 整单 fail，不得进 6.2；qc 里有 fail 项而 status=pass 是校验 error。  
`validate_keyframes` 还查：`first_last` 必有 `last_frame_file`、首尾文件都在盘上、紧景别必有 `plastic_face` 和 `anatomy`、qc 值只能是 pass / fail / n/a。  
近景继承 anti_plastic，但不得改写 shot_spec 的光线方向。  
落盘用 `scripts/place_codex_frame.py --parent …`：首帧必须写父图（本场空镜或上一镜已锁首帧），尾帧默认本镜首帧；脚本在 jpg 旁写 `SHxxx.json` 记父图、源文件哈希、被替下的旧版。审阅页 `REVIEW.html` 按它并排显示父图。
