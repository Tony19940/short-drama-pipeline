# 交接字段表

每岗只收表内输入，只交表内输出。缺必填项 = 未完成，统筹打回。  
字段名固定，下游按字段取值，不要解析散文。

通用头（除统筹外，每份产出都带）：

```text
project_id
episode_no          可空（小说岗可空）
scene_id            可空
shot_id             可空
agent               本岗名称
version
status              draft | ready | rejected
reject_reason       status=rejected 时必填
```

## 0. 制片统筹

**输入** `from_agent` `artifact` `required_fields_ok` `gates`

**输出**

|---|---|---|
| decision | 是 | pass / reject |

| reject_to | decision=reject 时是 | 打回哪一岗 |

| gates.storyboard_approved | 进 6.2 前是 | 关键帧是否过审 |
| gates.video_approved | 进剪辑前是 | 视频是否过审 |
| gates.package_confirmed | 进 6.1 前是 | 生成包是否经人确认 |
| gates.mute_test | 编剧/分镜交岗时是 | 静音后能否感到变化 |
| est_cost | 派 6.2 前是 | Σ duration_sec × 单价，按 target_model（单价见 VIDEO.md 路由表）；hardest 人审通过前只算不派 |

## 3. 视觉资产

**输入** `series_bible` `scenes[]`（人物、服装状态、场景、道具）

**输出 `assets[]`**

| 字段 | 必填 | 说明 |
|---|---|---|
| asset_id | 是 | 如 CHAR_SHENQING_COAT_V1 |
| type | 是 | character / costume_state / location / prop / creature / style |
| name | 是 | |
| binds_to | 是 | character_name / location_id / prop_name |
| file | 是 | 已生成的图片路径 |
| what_it_locks | 是 | 身份/服装/空间/道具，不是某镜构图 |
| version | 是 | |
| lock_card | 是 | 按类型从字段库摘出的锁定项；每项含 value 与 source |
| lock_card[].key | 是 | 如 hair_length, coat_color, time_of_day |
| lock_card[].value | 否 | 剧本未写则空 |
| lock_card[].source | 是 | script / inferred_empty |
| image_prompt | 是 | 只由 source=script 的字段生成 |
| quality_layer | 人物/服装必填 | 默认 anti_plastic。不是设定，是质量锁 |
| descriptor | character / costume_state 必填 | 一句：体型 / 发型 / 当前服装状态 / 动作相关手部道具。**不写年龄**。5.2 逐字贴进每条提示词并后接「100% 以参考图为准」 |
| voice_card | 有台词的 character 必填 | 1–2 句声线卡（音高、音色、节奏、口音、习惯），格式见 `knowledge/sound/vo.md`。5.2 逐字进 `audio_block` |
| stress_test | 锁 master 前 | `{count, recognized, passed}`：从候选 master edit 10 张不同姿势 / 光位 / 同框，≥9/10 认得出才 `passed=true`，否则改锁定卡 / descriptor 重试 |

style 资产必须含 `anti_plastic` 文本块，供人物 image_prompt 追加。  
anti_plastic 不得写入 lock_card 身份字段。  
`descriptor` / `voice_card` 的真源是 `01-bible/CHARACTERS.md`：每人一节 `## **slug** · 名`，行 `- **外形卡**：…`（换装变体 `  - <costume_state>: …` 或 `- **外形卡（<costume_state>）**：…`）、`- **声音卡**：…`；编包从这页读，写机器抄本 `.pipeline/voice_cards.json`（`schema: voice-cards-v1`）。assets[] 抄同一句，两处不一致以 CHARACTERS.md 为准。  
场景另出：3/4 机位空镜、每场一个锚点物、一套光逻辑；反打空镜 `02-assets/scenes/<id>/reverse.jpg`（空场景走场视频截帧 + 纹理）。人物可另试无头正面全身面板防中远景偷小脸。这两个文件 `place_codex_asset.py` 暂未收 slot，先手工落盘。

`lock_card` 按类型启用，不是全量必填：

- character / costume_state：人物枝（脸、身体、服装）。表情和姿势只许中性。
- creature：生物枝，仅剧本有生物时。
- prop：物品枝。
- location：场景枝 + 时间枝（年代、季节、时刻）。日夜是场景版本，不是人物版本。
- style：全剧画风与光线气质。

不准输出 shot 构图图。不准发明 bible 里没有的角色和地点。  
`source=inferred_empty` 的字段不得写进 image_prompt，不得画进图。

## 4a. 场戏分析（导演阐述，`scene_cards.json`，`schema: scene-cards-v1`）

**输入** 本集完整剧本正文 + 编剧岗 `scenes[]` + `sets[]` + `LOOK.md` + 目标模型能力档 + `case_library[]`（`knowledge/cases/` 的 id 和标题）。

**调用** 一次 `analysis`，整集一次。拆镜之前跑；`run_design_table` 会自动先跑它。校验不过带 `fix_these` 重来一次。

**输出 `scene_cards[]`（每场一张，`director/direction.py::validate_scene_cards`）**

| 字段 | 必填 | 说明 |
|---|---|---|
| scene_id | 是 | 继承编剧岗；每场必须有一张，不许重复 |
| dramatic_question | 是 | 观众在这场等什么答案，一句问句 |
| turn.at | 是 | 翻转发生在哪句台词或哪个动作，**逐字引用**剧本 |
| turn.what_flips | 否 | power / information / attention / space / emotion |
| emotion_curve.start / peak / end | 是 | 0–10 整数；peak ≥ start |
| emotion_curve.peak_at | 是 | 最高点在哪个瞬间 |
| the_shot.moment | 是 | 这场的那一颗：最紧、最慢、最清楚的瞬间 |
| the_shot.scale | 是 | wide/full/medium/close/otc/insert/pov；机器要求它是全场最紧的景别 |
| the_shot.why | 是 | 一句 |
| reveal_order[] | 是 | 观众被允许看见东西的顺序，≥ 2 步 |
| pov | 否 | 这场谁的眼睛 |
| distance_strategy | 是 | 机位距离怎么随情绪变 |
| light_motivation | 是 | 光从哪来；同场 `key_dir` 的依据 |
| color_shift | 否 | 色温/饱和在哪一刻变 |
| silence_test | 是 | 静音后画面仍能读出的变化 |
| case_cards[] | 否 | `knowledge/cases/` 的卡 id，1–2 张 |

**输出 `visual_grammar`（全集一份，`validate_visual_grammar`）**

| 字段 | 必填 | 说明 |
|---|---|---|
| motifs[] | 与 scale_rhythm 至少一项 | `{id, subject, rule, when, scenes[], until_scene, from_scene, scale_not[], scale_in[], angle, height}`；`when` ∈ always / first_appearance / first_shot_in_scene；每条至少一项可查约束 |
| scale_rhythm | | 一句：这集景别怎么呼吸 |
| light_motivation / color_arc | 否 | |
| ending_hook.scale[] / note | 否 | 本集最后一镜允许的景别 |

镜头表校验（`film_grade_checks`）拿它逐条查：母题（`grammar_violations`）、那一颗是否落地且最紧、景别节奏（三镜同景别、平线、峰值后不回落）、同场光位（`light_checks`：镜像只许反打，left↔right 直跳是 error，`day_night` 和 bible 不符是 error）、邻镜差（`neighbor_checks`：景别/角度/左右/运镜/主体最多改两件）。  
人审页 `03-storyboard/scene-cards.draft.md`。导演台 `PUT /api/productions/<slug>/pipeline/scene_cards.json` 走同一校验。

## 4b. 候选与评审（`design.candidates.json`，`schema: design-candidates-v1`）

**调用** 每场按 `candidate_style` 拆 N 版（`GROK_DESIGN_CANDIDATES`，默认 3；`POST /agents/design {"candidates": N}`）：`coverage` 覆盖派 / `pov` 主观派 / `long_take` 少切派，N > 3 加自由变体。每版单独过 `validate_shot_table`（局部校验），不过带错误清单重来一次，还不过就丢。至少一版过才有评审。

**评审 `call = critic`**（`04b_分镜评审.md`，`director/design_critic.py`）

| 字段 | 必填 | 说明 |
|---|---|---|
| scores[].candidate | 是 | 候选序号，必须覆盖每一版 |
| scores[].dims | 是 | 七维各 0–10：reveal_order / the_shot / rhythm / silence / card_fit / continuity / model_risk |
| scores[].notes / fixes[] | notes 是 | 什么成立、什么会崩，具体到镜号；若选它最该改的 1–3 处 |
| pick | 是 | 序号 |
| why | 是 | 哪一维决定的 |
| merge | 否 | 「用第 X 版，把 SHxxx 换成第 Y 版的那颗」 |

评审不可用时 `fallback_verdict` 机器兜底：警告数少、那一颗落地且最紧、景别跨度大。`source` 记 critic / deterministic / single / human。

**落盘**

| 文件 | 内容 |
|---|---|
| `.pipeline/design.candidates.json` | `scenes[] {scene_id, scene_card, candidates[] {style, label, shots[], warnings[], attempts}, verdict, pick}` + `picks{scene_id: 序号}` |
| `.pipeline/shot_list.json` | 只收被选的那版；表头带 `scene_cards`、`visual_grammar`、`candidate_picks` |
| `03-storyboard/shot-candidates.draft.md` | 并排对比页：机器指标 + 评审七维 + 每版镜头 |

**人改选** `POST /api/productions/<slug>/design/pick {scene_id, candidate}` → `pick_candidate`：换版、重编号、重校验、重渲染，不花 token。`verdict.source = human`。`GET .../design/candidates` 返回候选并附每版 `metrics`（镜数、总秒、景别曲线 W F M O C I、最紧、静止比、对白后反应、那一颗落地/最紧、警告数）。

## 4. 分镜设计（镜头表，`schema: shot-table-v2`）

**输入** 本集完整剧本正文 + 编剧岗全部 `scenes[]`（含 `scene_job / start_state / end_state`）+ `sets[]` 轴 + `LOOK.md` + 目标模型能力档（`director/video_profiles.py`，含 `experience[]` 模型经验）+ 4a 的 `scene_card` / `visual_grammar` + 命中的 `case_cards[]` 全文 + 本版 `candidate_style`。

**调用** 一次 `header`（表头：视点、每场左右锁、连戏圣经、每场镜数/秒数/节拍计划；已看见场卡），然后一场一次 `scene` × N 版。每版单独过机器校验，不过就带着错误清单重来一次。

**输出 `shot_list`**

| 字段 | 必填 | 说明 |
|---|---|---|
| schema | 是 | `shot-table-v2` |
| target_model | 是 | 设计时对着哪份能力档 |
| whose_pov | 是 | 全集主视点 |
| left_right_lock | 是 | 对象，键 `scene_id`。值一句话（旧：轴=底板）或 `{plate, axis}`（`background`/`line` 同义）：底板是墙/门/柜，轴是人物线。同场机位必须轴同侧，不要把底板锁当成每帧墙不能左右翻 |
| continuity_bible.eyeline / wardrobe | 是 | 每场谁看什么；谁穿什么、什么时候变 |
| continuity_bible.day_night | 是 | 对象，键 `scene_id` |
| continuity_bible.props[] | 是 | `{name, first_scene, last_scene, note, assets[], aliases[], attached_to}`。last_scene 之后再出现即穿帮。`assets` 是资产 `binds_to`（一件道具的两种状态写两个），`aliases` 是文案里会怎么叫它，`attached_to` 是随身在谁身上 |
| continuity_bible.cast_assets | 否 | 对象，编剧 cast id → 资产 `binds_to`，只在两边名字对不上时写（如 `khmer_patrol → patrol`） |
| continuity_bible.evidence[] | 否 | `{what, scene_id}`。观众必须看清的证据，由某一镜的 `evidence[]` 认领，且不许在 wide |
| scene_plan[] | 是 | `{scene_id, target_shots, target_sec, beats[]}` |
| total_sec | 自动 | 各镜 `duration_sec` 相加 |
| shots[].shot_id / scene_id / location_id | 是 | `SH001` 全集连续；地点必须等于编剧场的 `location_id` |
| shots[].beat / shot_job / coverage_type | 是 | coverage 加 `pov / follow` |
| shots[].scale / angle / height / lens | 是 | wide/full/medium/close/otc/insert/pov；eye/high/low；`24mm`–`85mm` |
| shots[].move_type / move_reason | 是 | 默认 static；动要理由；只能选能力档 `allowed_moves` |
| shots[].left / right / eyeline | 是 | 同场同一对象不许左右翻 |
| shots[].body_facing | 否（有人在画时应写） | `朝镜头` / `四分之三` / `侧脸` / `背对镜头` / `无人`。不是 eyeline。过肩禁止背对 |
| shots[].camera_side | 否 | `front` / `front-left` / `front-right` / `behind` / `left` / `right` |
| shots[].one_action | 是 | 一个主动作，一镜一地点 |
| shots[].internal_cuts[] | 否 | `{at_sec, scale, one_action}`；默认空。Seedance 2.0 / 2.5 的 `max_internal_cuts=0`；只在未来某剧打开能力档时可用 |
| shots[].duration_sec | 是 | 纸面秒，可一位小数。桶：反应 1.2–2.0 / 插入 1.5–2.5 / 对白 2.5–4.5 / 建立 3–5 / 长镜 5–8。>8 须 `shot_job` 含「信息在连续时间里」。≤ 能力档上限；低于模型 min 只警告（渲染按 min、剪辑裁） |
| shots[].dialogue_ref[] | 是 | `{character, line}` 原句；≤ 2 句；全场每句台词必须落到且只落到一镜 |
| shots[].dialogue_delivery | 是 | none / post / on_camera（on_camera 需能力档 `native_dialogue_audio`） |
| shots[].key_sfx[] / light | 否 | 音效合同。E+ 用 `mix_episode_sfx.py` 按此混床，不另编点声。`light = {day_night, key_dir, quality, color}` |
| shots[].in_from / out_to | 是 | 本镜机位上的起幅 / 落幅。`in_from` = 第 0 秒的动作起点状态（动词可已起手，禁结果）；`out_to` 才是结果。不是下一镜机位，不写立刻切 / 切到 / 片内切 |
| shots[].evidence[] | 否 | 认领表头 evidence.what |
| shots[].visual_turn / hardest | 否 | |
| shots[].emotion_level | 否 | 0–10 整数。场卡 `emotion_curve` 落到每镜；峰值镜最紧，峰值后要回 medium 以上，否则警告 |
| shots[].camera_id | 否 | `sets[].cameras[]` 的机位 id。写了就按顶视图几何查：不存在 = error；设计的 left/right 和 `suggest_sides` 不一致 = warning |
| scene_cards / visual_grammar / candidate_picks | 自动 | 表头带上 4a 的卡和语法、4b 的选版；有卡就跑 `film_grade_checks` |
| shots[].state | 是（一镜有则全表必有） | 这一镜的世界状态：`characters{cast_id: {costume, binding, bound_with, carrying[], in_frame}}`、`props[]`（在场的固定道具，资产 `binds_to`）、`location`（空镜变体，如 `ancient-shoal-night`）、`note`（一行给出图看的连戏句：穿什么、怎么绑、什么必须在/不在）。`binding` ∈ none / wrists_front / wrists_behind / pillar / snared / held；不是 none 就必须写 `bound_with` |
| shots[].state_changes[] | 变了才写 | 相对上一镜谁的什么变了，形如 `sokha.binding`、`sokha.costume`、`sokha.carrying`。没声明就变 = 校验 error |
| shots[].acting | 否 | 键 cast id / 显示名 → `{want, hide, business, muscle, change}`。`want` / `hide` 是内心线，不进画；`business` / `muscle` / `change` 是镜头看得见的事，情绪形容词出现在这三格或 `expression` 里 = warning `acting_adjective`。7a 写的同名字段同形；编包按此翻成动作句 |
| speech_mode（表头） | 否 | `seedance_native` / `post_dub`。不写则能力档有 `native_dialogue_audio` 即 native，否则 post_dub |
| visible_change_without_dialogue | 是 | pass |
| dropped_shots[] / design_steps_done | 否 / 自动 | |

不准带：prompt、video_prompt、image_prompt、motion_prompt、asset_id、image_file、frame_description（画面是 7a 的事）。

## 7a. 画面描述（第二描述层，`frame_descriptions.json`，`schema: frame-desc-v1`）

**输入** 锁定或草稿的 `shot_list`（每镜合同字段）+ 该场 `scene_card` + `visual_grammar` + 该场 `set` + `LOOK.md` / `LOOK-LOCK.md` + 人物卡。

**调用** `frame_desc`，一场一次（`POST /agents/frame_desc {"scene_ids": [...]}` 可只补几场）。在拆镜之后、关键帧之前；镜头表改了就重写那几场。

**输出 `items[]`（每镜一条，`director/frame_desc.py::validate_frame_descriptions`）**

| 字段 | 必填 | 说明 |
|---|---|---|
| shot_id | 是 | 必须是表里的镜；表里每镜必须有一条 |
| layers.foreground / midground / background | 是 | 三层各有什么，真没有写 `无` |
| light.key | 是 | 主光从画面哪边、什么光源；和同场前几镜一致 |
| light.fill / practical / quality | 否 | 补光、画里看得见的光源、硬软/色温 |
| subject.facing 或 subject.hands | 至少一项 | 身体朝向；手在哪做什么（空镜写 `无人`） |
| subject.holding / micro_expression | 否 | 起幅拿着什么。`holding` 是 t=0，不是动作结果。`micro_expression` 写肌肉（咬牙、鼻息、垂眼），不写情绪词 |
| acting | 有人在画则是（新写） | 键 cast id → `{want, hide, business, muscle, change}`：要什么 / 藏什么 / 手上的事 / 哪块肌肉在动 / 拍点在哪一秒、身体上怎么看得出。空镜 `{}`。五格都是可见的事 |
| still_start | 否（新写必填） | `{pose, holding, prop_state, one_paragraph}`。首帧第 0 秒 = 动作起点状态：可已起手，禁结果。旧件可缺，缺则用 `one_paragraph` |
| still_end / last_paragraph | first_last 时是 | 尾帧落幅。旧件缺此字段：Agent 重跑时 error；Gate C2 只 warning，避免 15 集锁死 |
| composition.weight | 是 | 重心在画面哪里 |
| composition.negative_space / headroom | 否 | |
| height_meaning | 否 | 这机高说了什么 |
| forbidden[] | 否 | 这一镜画面里不得出现的东西（脚、汉字、第二光源…以及 one_action 的完成态） |
| one_paragraph | 是 | ≤ 220 字，**只写首帧第 0 秒**。禁止把 `one_action` 的动词结果写进首段 |

校验另查：空形容词（电影感 / 氛围拉满 / 高级感 / 大片感…）= error；「真人 / photoreal / live-action」= error；情绪形容词（愤怒 / 悲伤 / 冷 / 横 / 夸张表情 / 面露 X 色…）出现在 `one_paragraph` / `still_*` / `micro_expression` / `acting` = **warning `acting_adjective`**。  
`one_action` 为变换动词（扔/捡/开/关/塞进/拿出/抹/穿/甩…）且首帧文本已写完成态（已在手里 / 已打开 / 已落地 / 已入袋…）= **error**（`validate_frame_descriptions`，Agent 重跑时）。起手态（手已伸向 / 已俯身 / 手已搭上把手）不是完成态，放行。Gate C2 锁同一条只 **warning**，不打回旧集。`in_from` 是起幅而首段是结果 = error。`first_last` 缺 `still_end` / `last_paragraph` = error（Agent）；C2 warning。  
下游：`compile_keyframe_prompt_zh(..., slot=first)` 用 `still_start` / `in_from` / 起幅 holding，**不把 `one_action` 当作要画的画面**；`one_action` 只以「起点状态：可已起手，结果不画进首帧」出现（`still_t0.py`）。`slot=last` 用 `still_end` / `out_to`。`image_prompt` 仍插「画面描述：…」。每个生成包带 `frame_description`（首帧段）；`first_last` 另带 `last_image_prompt`。`shot-list.draft.md` 每镜下多一行画面描述。人审页 `03-storyboard/frame-descriptions.draft.md`。分镜岗不得自己写 `frame_description`。
