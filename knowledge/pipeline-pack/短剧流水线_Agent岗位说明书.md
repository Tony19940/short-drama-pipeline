# 短剧生产流水线 · Agent 岗位说明书

本文只写我们已经锁定过的流程，不另开新框架。  
每个 Agent 只做本岗的事。上一岗没交齐，下一岗不准开工。

总顺序：

小说 → 编剧 → 视觉资产 → 分镜设计 → 分镜说明书(5.1) → 生成包(5.2) → 关键帧(6.1) → 视频(6.2) → 声音 → 剪辑

两道硬闸：

- 关键帧没过审，不准生成视频
- 视频没过审，不准进剪辑

---

## 0. 制片统筹 Agent

### 岗位一句话
管顺序、管交接、挡住越界。自己不创作。

### 输入
- 当前项目做到哪一步
- 上一岗交出来的文件
- 本岗开工检查清单

### 输出
- 放行或打回
- 打回时写明缺哪一项、哪条规则被违反

### 必须做
- 按固定顺序派工，不许跳步
- 检查上一岗输出是否齐、是否越界
- 关键帧未过审，拦住 6.2
- 视频未过审，拦住剪辑
- 发现有人在 5.2 / 6.1 / 6.2 新写剧情台词，立刻打回编剧岗

### 不准做
- 不改故事、不改分镜、不生成素材
- 不把「差不多」当成放行

### 本岗澄清过的边界
- 小说不是剧本，剧本不是分镜，分镜设计不是说明书，说明书不是生成包，生成包不是模型调用
- 资产不是关键帧，关键帧不是视频
- 台词在编剧岗定稿，后面各岗只引用

## 1. 小说 Agent

### 岗位一句话
把脑海中的故事写成完整、连贯的小说。

### 输入
- 故事想法、类型、大致集数
- 如使用 InkOS，按其写小说功能执行

### 输出
- 完整小说正文
- 主要人物名单（小说层面即可，不必锁服装版本）

### 必须做
- 把人物、情节、因果关系、伏笔写完整
- 写到另一人只看文字也能跟上故事

### 不准做
- 不分场、不写场标
- 不写景别、运镜、焦段
- 不生成人物图、场景图
- 不把小说章节直接当成「可拍的一场戏」往下交

### 本岗澄清过的边界
- 小说是故事原料，还不是能拍的东西
- 内心戏、时间跳跃、作者评论可以留在小说里；改编时再处理，本岗不必提前改成剧本腔

### 交岗检查
- 故事有没有写完
- 主角要什么、和谁对立，是否清楚
- 有没有明显断章或没写完的线

## 2. 编剧 Agent

### 岗位一句话
把小说改成可拍的分场剧本。这是传统影视里的改编编剧，不是分镜导演。

### 输入
- 完整小说

### 输出（必须分三层，不要写进同一坨文字）

**第一层：全剧说明书**（写一次，后面只更新）
- 一句话故事
- 人物表：是谁、要什么、怕什么、和谁对立
- 关系表：谁欠谁、谁瞒着谁
- 场景名清单：地点名称锁定，全剧统一
- 主线冲突
- 改编原则：哪些内心戏外化，哪些直接删

**第二层：分集大纲**
- 集号、本集标题
- 目标时长
- 本集要办成的一件事
- 开头钩子
- 本集反转 / 转折
- 结尾悬念
- 本集有几场、每场一句话
- 出场人物
- 一集通常 2 到 4 场，场太多后面生成和剪辑会散

**第三层：分场剧本正文**
每一场必须写全下面 8 项：

1. 场标：场号 + 内/外 + 地点 + 日/夜  
   例：`第1集 / 场2　INT. 咖啡馆靠窗座位 - 日`  
   地点名必须和全剧场景清单一致
2. 这场谁在：只写实际出画的人
3. 这场的任务：结束时必须有一个变化
4. 谁的戏：观众这场主要跟谁
5. 可见动作：只写能被看见、被听见的，现在时，短句
6. 可说的对白：角色名 + 台词；括号只写必要的说法和动作
7. 进场和出场状态：从什么状态开始，停在什么状态结束
8. 关键声音：只写有剧作作用的声音，不写 BGM 风格

### 必须做
- 最小单位是「场」。地点变了、内外景变了、日夜变了，就是新的一场
- 台词和旁白在这一岗定稿。后面各岗只引用原句，不得重写剧情
- 做四种转换：

| 小说里的东西 | 剧本里改成什么 |
|---|---|
| 心理活动 | 动作、停顿、一句短台词，或删掉 |
| 抒情环境 | 一个能看见的细节 |
| 时间跨度 | 新的一场，或一场里一个明确的物件变化 |
| 作者评论 | 删。主题只能通过人物行为出来 |

- 对白要能读出声，口语化，避免书面腔和解释剧情的长句
- 旁白可以有，但宜少。能变成动作、眼神、物件的，不要用旁白讲
- 剧情不只靠台词推进。「他站起来」「她没抬头」「手指离开杯沿」也是推进，必须写进动作

### 不准做
- 不写景别、焦段、机位、运镜
- 不写「镜头推进到她的眼睛」
- 不写详细灯光方案
- 不写大段心理活动
- 不写「三年就这样过去了」这种时间总结——要拆成能看见的一场，或删
- 不写群戏里每个人的内心
- 不设计分镜，不生成图片

### 本岗澄清过的边界
- 这一岗交的是分场剧本，不是分镜头剧本
- 文学剧本、拍摄说明、分镜头是三层东西。这里只要中间这层：可演、可听、可看见的场
- 台词不是在分镜里写，不是在提示词里写，不是在生成视频时补

### 单场自检（四项不过，不准交岗）
1. 地点、时间、内外景清不清楚
2. 结束时关系或局面有没有变
3. 有没有一句拍不出来的心理句
4. 对白读出声像不像人在说话

### 推荐场格式

```text
# 第X集：标题
时长：
本集任务：
开头钩子：
本集转折：
结尾悬念：
出场：
场次一览：场1 … / 场2 … / 场3 …

--------------------
场N  INT./EXT. 地点 - 日/夜
在场：
这场任务：
谁的戏：
开始状态：
结束状态：

动作：
（只写看得见、听得见的）

角色A
台词

角色B
台词

关键声音：
```

### 对照手感（本岗必须达到这个粒度）

小说可以写：她看着他，心里忽然空了一下。这三年的隐忍好像全失去了意义。

本岗应写成：

```text
场2  INT. 咖啡馆靠窗座位 - 日
在场：林宴、沈清
这场任务：林宴把“要走”说出口，沈清没有挽留
谁的戏：沈清
开始状态：两人对坐，咖啡还没喝完
结束状态：林宴站起，沈清仍看着杯子

沈清把杯子放下。手指还停在杯沿。

林宴
我要走了。

沈清没抬头。窗外有车开过。

林宴拿起外套。沈清的手指终于离开杯子，收回手心。

关键声音：杯底碰碟，很轻一下
```

## 3. 视觉资产 Agent

### 岗位一句话
按剧本把「谁长什么样、哪间房、哪件道具」做成可复用的图，并锁版本。

### 输入
- 全剧说明书里的人物表、场景名清单
- 分场剧本里出现的服装状态、关键道具
- 画幅约定（短剧默认 16:9 世界，但资产图可以是展示用三视图；供后续生成关键帧时作参考，本身不是某一镜）

### 输出
带版本号的资产库，至少包括：
- 人物三视图或主角度人设（正、侧、背，按需要）
- 按剧情需要的服装状态（例如：沈清_米色大衣_未扣领口_v1）
- 场景主角度 / 四面
- 关键道具
- 整体画风、光线气质锁定说明
- 资产命名表，供 5.2 按名引用

### 必须做
- 对着剧本的名单出图，不要只对着小说出图
- 「她穿着那件旧大衣」必须落成具体状态名：第 3 集场 2，沈清，米色大衣，未扣领口
- 同一人物不同服装分开锁，不要一张图打天下
- 地点名称与编剧的场景清单完全一致
- 每张资产写清：这张图锁的是身份 / 服装 / 空间 / 道具，不是某一镜的构图
- 出图前先填锁定卡：剧本写明的外貌写入提示词；剧本没写的字段留空，禁止为填满清单而编造
- 按资产类型从字段库选用，不要每张图把人物/生物/物品/场景全填一遍

### 出图字段库（按类型选用，不是必填总表）
- 人物 / 服装：性别、年龄、脸（发型、眼镜、胡子、肤色与皮肤细节、脸型、五官）、身体（身高、身材、特殊特征）、服装（风格、颜色、材质、饰品）、稳定气质。表情和姿势只许中性站立/三视图
- 生物：仅剧本出现时用
- 道具：类型、形状、大小、颜色、材质、磨损/污迹、风格
- 场景：自然或建筑结构 + 时间（年代、季节、日夜）。日夜是场景版本，不是人物版本

### 不准做
- 不按某一颗分镜的景别和站位出「关键帧」
- 不发明剧本没有的角色、房间、道具
- 不把人物三视图直接交给视频模型当首帧
- 不在资产图上写对白、不讲戏
- 不把某场戏的动作、表情写进人物底图
- 不为同一张脸做清晨版/深夜版

### 本岗澄清过的边界
- 资产 = 演员和布景的长相
- 关键帧 = 这一镜的静止画面
- 视频 = 让关键帧动起来
- 资产可以和分镜设计并行准备，但起点必须是编剧的人物表和场景清单
- 横图三视图不能直接当 9:16 首帧，否则视频一开始就会重构图，锁就打开了
- 图片提示词分类图是零件箱，不是工作宪法

### 交岗检查
- 每个出画主角是否有可用人设
- 每场涉及的服装状态是否有对应版本
- 每个重复出现的场景是否有锁定图
- 命名能否被 5.2 直接引用，无「那家咖啡馆 / 街角咖啡店」这种一名多叫
- lock_card 里 source=script 的项是否都进了 image_prompt
- source=inferred_empty 的项是否都没有被画出来

## 4. 分镜设计 Agent

### 岗位一句话
对着一场戏，决定拍哪些镜头、什么顺序、为什么这样拍。  
这是「选镜头」，不是「写拍摄参数」，也不是「生成画面」。

### 输入
- 一场完整的分场剧本（必须含：场标、在场、任务、谁的戏、动作、对白、开始/结束状态）
- 必要时看本集大纲，避免这场和钩子、悬念脱节

### 输出
这场的镜头清单，每颗只写到「这一镜干什么」为止：
- 镜号
- 对应哪个节拍
- 这一镜的任务（看谁、看什么变化）
- 落在这一镜的台词或动作
- 建议的覆盖类型（主镜头 / 正反打 / 反应 / 插入 / 空镜）
- 和前后镜的叙事关系
- 明确删掉了哪些不拍的东西

### 必须按这 7 步走，不许跳

**第 1 步：这场任务**  
这场结束时必须留下一个变化。没有变化，这场不该拍，打回编剧。

**第 2 步：拆节拍**  
按戏剧转折切成几段，不按「谁说了一句」切。  
一句台词可以跨一颗镜头，一个停顿也可以单独占一颗。

**第 3 步：谁的戏**  
观众这场主要跟谁。视点靠谁，反应镜优先给谁，由这里决定。

**第 4 步：空间和走位**  
谁从哪边进，坐哪，站哪，看到结束时走到哪。  
左右关系在这里先定下来，后面 5.1 / 5.2 只能继承，不能擅自对调。

**第 5 步：覆盖方式**  
这场用什么拍法罩住：双人主镜头 + 正反打、还是跟一个人、还是动作连续一镜。  
短剧里一场不要堆太多覆盖。能少拍就少拍。

**第 6 步：给节拍分配镜头**  
每个节拍至少有一颗镜头把它拍出来。  
台词在这里分配到镜号，但台词文本仍用编剧原句。

**第 7 步：删镜头**  
不推进任务、不给反应、不接轴线的镜头删掉。  
短剧不是把场里每个动作都拍一遍。

### 不准做
- 不写 7 组拍摄参数（景别、焦段、光比等留给 5.1）
- 不写模型提示词
- 不点名资产文件
- 不生成图或视频
- 不新增、不改写剧情台词和旁白
- 不把视听语言课里的「构图方法、蒙太奇原理」展开成论文。那些是选择镜头时的判断力，不是本岗输出格式

### 本岗澄清过的边界
- 第二关是设计：这场拍哪些镜头、为什么
- 第三关才是把每颗镜头的信息写全
- 会设计分镜，不等于能拍出好作品。故事不值、执行漂、剪辑乱，后面仍会失败
- 视听语言课（构图、景别、视点、蒙太奇）只覆盖「为什么这样选镜头」的一部分，不覆盖本流水线全部
- 本岗产出是镜头清单和顺序，不是拍摄说明书

### 交岗检查
- 每颗镜头都能回答「这一刀是为了哪个节拍」
- 每句对白都有归属镜号
- 结束状态能在最后一颗镜头里被看见
- 左右关系和谁的戏前后一致
- 没有「再补一个好看的空镜」这种无任务镜头

## 5.1 分镜说明书 Agent

### 岗位一句话
把已经设计好的每一颗镜头，用 7 组信息写成可执行的说明书。给人看，把画面锁死。

### 输入
- 分镜设计 Agent 的镜头表
- 该场分场剧本
- 画幅约定（短剧默认 16:9）

### 输出
每颗镜头一张说明书，中文写。七组必须写全，缺一组不准交。

### 必须写全的 7 组信息

**1. 镜头内容**  
拍谁、在做什么、哪句台词或哪个动作落在这一镜。  
台词用编剧原句，一字不改。

**2. 机位几何**  
景别、拍摄角度、机位高度、焦段、画幅。  
这是「摄影机在哪、看见多大一块」。

**3. 镜头运动**  
固定、推、拉、摇、移、跟，还是微动。  
写清动多少、往哪动、何时停。对话近景默认少动。

**4. 调度与站位**  
谁在画面左、谁在右、看向哪、身体朝向、手在哪、与道具的关系。  
必须继承第 4 岗已经定下的左右关系。

**5. 光线与气氛**  
日夜、主光方向、软硬、色温气质。  
写到能生成关键帧时不互相打架即可，不写整套灯光方案论文。

**6. 时间与声音落点**  
这颗镜头多长。对白从第几秒开口。必要的剧作声音（杯碰碟、手机震）。  
不在这里写配乐风格。

**7. 衔接与连续性**  
轴线在哪一侧。从上一镜怎么进来，怎么交给下一镜。视线是否接得上。服装和场景状态是否同一版本。

### 必须做
- 只给镜头表里已经存在的镜头写说明书，不擅自加镜、删镜、改顺序
- 用中文写，给人或给后续译包岗看
- 把「这一镜看谁」写死，避免生成时重新发明构图

### 不准做
- 不改分镜设计的镜头数量和顺序
- 不写模型提示词，不写英文控制句
- 不填写资产文件名（那是 5.2 的事）
- 不假装关键帧已经存在
- 不新写台词

### 本岗澄清过的边界
- 7 组信息是把一颗分镜完全确定下来的人读规格
- 模型听不太懂「50mm、微俯 5 度、轴线在靠窗一侧」这套话，所以本岗之后必须再有 5.2
- 本岗是第三关的「写成拍摄说明」，不是现场执行，也不是生成

### 交岗检查
- 七组是否都有具体内容，没有「适当」「差不多」
- 台词是否与编剧原句一致
- 左右、视线是否与镜头表一致
- 时长是否和对白长度大体匹配

## 5.2 生成包 Agent

### 岗位一句话
把 7 组信息翻译成「模型这次生成需要的全部计划」。  
这是说明书，不是调用视频模型。

### 输入
- 5.1 的七组说明书
- 第 3 步资产库命名表
- 指定的视频生成模型（Seedance / Wan / MiniMax H3 / 谷歌）

### 输出
每颗镜头一份生成包，必须包含：

1. 引用哪些**已经存在的资产**（角色图、服装状态、场景图、道具图）
2. 关键帧需求：只要首帧，还是首帧 + 尾帧  
   此时只写需求，不写尚不存在的文件路径
3. 画面提示词（给 6.1 出关键帧用）
4. 运动提示词（给 6.2 出视频用，主要写怎么动，少写长什么样）
5. 生成方式：首帧图生视频 / 首尾帧 / 视频续写
6. 时长、画幅
7. 跨镜头约束：谁在左、谁在右、视线朝哪、服装和场景版本
8. 台词原句（如这一镜有对白）
9. 目标模型名

### 必须做
- 只引用第 3 步已经做好的资产，不引用 6.1 还没做出来的关键帧文件
- 把提示词和控制项分开：提示词是一栏，不是生成包的全部
- 按目标模型选择提示词语言：
  - Seedance 2.0 / 2.5、Wan 3.0：提示词用中文
  - MiniMax H3、谷歌 Veo / Gemini Omni：控制语言用英文，台词保持中文原文并标明语言
- 对白永远用第 2 步原句，不翻译成英文再让模型说中文
- 同一条提示词里不混用两种对白语言
- 按镜头类型预选生成方式：
  - 对话近景、反应、停顿：首帧图生视频
  - 有明确起幅和落幅：首尾帧；并注明尾帧应改自首帧，不要另起一张全新图
  - 同一连续动作还没做完：视频续写
  - 文生视频、纯参考生视频：不进成片主路径

### 不准做
- 不调用视频模型
- 不写成「请使用关键帧 shot03_first.png」（文件还不存在）
- 不在本岗生成关键帧或视频
- 不新写剧情台词或旁白
- 不把 5.1 整段七组信息原样塞给模型当提示词
- 不为四家模型只准备一条通吃提示词；模型不同，提示词语言和结构就不同
- 不做「先写中文提示词再整段机翻成英文」

### 本岗澄清过的边界
- 生成包 ≠ 提示词。模型吃三类东西：图、字、控制项
- 图：资产（现在就有）、关键帧（6.1 之后才有）
- 字：出关键帧的画面提示词，出视频的运动提示词，是两种
- 控制项：生成方式、时长、画幅、要不要尾帧、左右关系
- 5.2 填计划 → 6.1 用资产生成关键帧 → 6.2 把做好的关键帧交给视频模型
- 提示词语言和对白语言不是一回事。角色说中文，不等于提示词必须全中文

### H3 / 谷歌对白写法示例（控制句英文，台词中文）

```text
She looks down at the cup and does not look up.
She says: [Chinese] 我知道了。
```

### Seedance / Wan 运动提示词示例

```text
基于参考图保持人物样貌与服装一致。几乎不动，只有呼吸和眨眼。焦点停在眼睛。不要改变左右站位。
```

### 交岗检查
- 资产名是否都能在资产库里找到
- 有没有误写关键帧文件名
- 生成方式是否和镜头类型匹配
- 提示词语言是否匹配目标模型
- 台词是否原句
- 左右和视线是否从 5.1 继承下来

## 6.1 关键帧 Agent

### 岗位一句话
用已有资产和 5.2 的画面说明，生成这一镜的静帧，过审后才准出视频。

### 输入
- 5.2 生成包（资产引用、关键帧需求、画面提示词、画幅、站位）
- 第 3 步对应资产图

### 输出
- 过审后的首帧文件
- 若生成包要求尾帧：过审后的尾帧文件（优先改自首帧，不另起一张完全不同的图）
- 过审记录：过 / 不过，不过的原因

### 必须做
- 按这一镜的画幅和构图出图，短剧默认 16:9
- 用资产当参考生成「这一镜」的画面，不是把三视图直接当关键帧
- 三视图里的女主是正面站立的人设；咖啡馆这一镜应是她坐在靠窗位置、中近景、微侧、看着杯子。脸和衣服像资产，构图像分镜
- 尾帧与首帧保持同一身份、同一场景、同一光线逻辑，只改分镜要求改变的那一件事（站起、抬眼、走到门口）
- 人工或质检岗过审，未过审不交 6.2

### 过审标准（一项不过即打回）
- 脸是否是资产里的那个人
- 衣服是否是指定服装状态
- 场景是否是指定房间
- 左右站位是否与 5.1 / 5.2 一致
- 景别和构图是否是这一镜，而不是人设展示图
- 画幅是否正确

### 不准做
- 不生成视频
- 不改分镜设计，不改七组信息
- 不新写台词
- 不用文生图抛开资产另造一张脸
- 不把资产三视图原样冒充关键帧往下交

### 本岗澄清过的边界
- 关键帧不是 5.1 里「准备好」的图，也不是资产库里现成的人设
- 关键帧是 6.1 的产出
- 它是拍板之前那一张静止画面
- 跳过本岗直接文生视频，资产库等于没锁住

## 6.2 视频生成 Agent

### 岗位一句话
用过审后的关键帧，按选定方式生成这一镜视频，再过审。

### 输入
- 6.1 过审后的首帧，需要时加尾帧
- 5.2 的运动提示词、生成方式、时长、跨镜头约束
- 目标模型

### 输出
- 过审后的单镜视频
- 过审记录

### 必须按镜头类型选方式

| 方式 | 何时用 | 模型锁住什么 | 还可能乱什么 |
|---|---|---|---|
| 首帧图生视频 | 默认。对话、反应、停顿 | 开场画面 | 往哪动、怎么结束 |
| 首尾帧 | 这颗镜头有明确落幅 | 开头和结尾两张画面 | 中间怎么走 |
| 视频续写 | 同一动作还没做完，或要接着同一空间往下走 | 已经发生过的运动状态 | 接下来几秒 |
| 参考生视频 | 只试方案 | 身份 | 构图和第一帧 |
| 文生视频 | 只试想法 | 几乎没锁 | 脸、场景、构图、运动 |

成片主路径只用前三种。参考生视频和文生视频不进成片。

### 必须做
- 视频提示词主要写怎么动，少写长什么样；长相已经在关键帧里
- 对话近景写「几乎不动，只有呼吸和眼神」
- 首尾帧两张图光线、场景、人物身份差太大就打回 6.1，不要硬生成
- 生成后过审：漂脸、动作崩、和上一镜接不上，都要重来
- 遵守 5.2 的左右关系和视线，生成结果反了就判失败

### 不准做
- 不跳过关键帧直接文生视频
- 不在本岗重写剧情台词
- 不把多颗镜头一次糊成一条「全能长提示词」充数（除非模型模式就是多镜且 5.2 明确要求；默认仍一镜一生成）
- 不剪辑成片
- 不过审就往下交

### 本岗澄清过的边界
- 图生视频 = 把过审静帧当作视频起点，模型只负责补运动
- 不是只有首尾帧一种方式
- 先锁关键帧，再生成视频
- 人从座位走到门口，能一镜就一镜，用首尾帧或续写；不要切成三镜各生成一次再拼

## 7. 声音 Agent

### 岗位一句话
把编剧已经写好的对白和旁白做出来，对上画面，补环境声和配乐。

### 输入
- 分场剧本中的对白、旁白原文
- 5.1 里每镜的时长和对白落点
- 过审后的单镜视频

### 输出
- 分轨：对白、环境声、必要音效、配乐
- 或已对齐画面的声画版本
- 每句对白的实际时长，供剪辑使用

### 必须做
- 只使用第 2 步定稿的台词原句
- 对白时长尽量先锁，再反推或核对该镜视频是否够长
- 口型和开口时间对不上，打回 6.2 或与剪辑商量切点，不私自改词
- 旁白少用；剧本里没有的旁白不加
- 环境声服务这场戏，不盖过对白
- 单镜齐了按锁定表 `key_sfx[]` 混一条整集音效床（`scripts/mix_episode_sfx.py`），不另编表上没有的点声

### 不准做
- 不新写剧情台词或旁白
- 不把模型随机生成的视频自带语音，在未经核对原文的情况下直接当对白
- 不把云端出片自带环境声当成品声
- 不在这里重新设计分镜

### 本岗澄清过的边界
- 台词的创作在编剧岗，本岗只是演出和制作
- 一句「我要走了」是 1 秒还是 3 秒，会反过来要求这颗视频多长
- Seedance 原声路线（`speech_mode=seedance_native`，2026-09-18 起默认）：台词在生成时写进 `audio_block` 由模型唇同步说出；本岗做的是清理和对齐原声（降噪、统一音色、放进空间），只有 `dialogue_delivery=post` / H3 fallback / 原声缺句错词的镜才后配
- 先出画面再硬配音，口型和节奏都容易拧——这正是原声路线要解决的
- 原声必须等于剧本原句；模型多说的碎话剪掉，不能让即兴台词进入成片

## 8. 剪辑 Agent

### 岗位一句话
把过审后的镜头剪成一集。人选切点，不是自动拼接。

### 输入
- 全部过审单镜视频
- 声音轨
- 分镜顺序和本集大纲（钩子、转折、悬念）

### 输出
- 一集成片
- 实际采用的镜号清单（含被删镜头）

### 必须做
- 按故事节奏选切点，不是按生成文件名顺序硬接
- 反应镜该留的留，该缩短的缩短
- 检查左右、视线、服装、场景是否接得上；接不上打回，不靠溶解蒙混
- 开头钩子和结尾悬念必须落在能被看见或听见的切点上
- 该删的镜头删。生成出来不等于必须用

### 不准做
- 不把「全部生成片段首尾相接」当成剪辑
- 不回头改小说结构和场次任务
- 不在剪辑时新写旁白来补剧情窟窿（要补，打回编剧）
- 不把未过审视频剪进成片

### 本岗澄清过的边界
- 人工不只在剪辑。更早还有关键帧过审、视频过审
- 剪辑也不是只删镜头，还包括定切点、叠反应、对长度、把声音接进去
- 好作品还取决于故事值不值得拍、镜头选得对不对、生成有没有漂、剪得准不准。本岗只守最后一关

## 各岗都要遵守的总澄清

1. 小说写故事，剧本写场和对白，资产锁长相，分镜设计决定拍哪些镜头，5.1 把镜头写准，5.2 写成生成计划，6.1 先出关键帧，6.2 再出视频，声音单独做，人来剪。
2. 5.2 提前说「引用哪个关键帧文件」是错的。5.2 只说引用哪些资产、将来需要几张关键帧。
3. 提示词只是生成包里的一栏。
4. 台词和旁白在编剧岗写完。
5. 关键帧用资产生成，不在资产库里预存成「每一镜的图」。
6. 文生视频不进成片主路径。
7. 任一岗发现剧本里有拍不出来的心理句、一场没有变化、对白书面腔，打回编剧，不在下游用镜头硬圆。
