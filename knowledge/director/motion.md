# 运镜写法（借鉴电影运动语言，不接可灵接口）

模型听得懂规则、速度、区域，听不懂“很有氛围”。

1. 先写摄影机契约：static / push / pull / pan / track 五选一，写成硬规则。
2. 速度要带时间：slow push in over the full shot，不要只写 slow。
3. 画面分区：左/中/右或前景/中景/背景，写清哪一块不许乱。
4. 一镜一次动作。焦点变化也要有起止，不要空喊浅景深。
5. 禁止项单独写，且不能空。

横屏都市剧禁用：环绕、闪摇、无人机、crash zoom、IMAX。画幅默认 16:9，不要写成 9:16，除非该剧 confirm 锁了竖屏。
宫格预览只给人/导演 Agent 看整场，不拿去出视频。
