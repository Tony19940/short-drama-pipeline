# 运镜写法（借鉴电影运动语言，不接可灵接口）

模型听得懂规则、速度、区域，听不懂“很有氛围”。

1. 先写摄影机契约：static / push / pull / pan / track 五选一，写成硬规则。
2. 速度要带时间：slow push in over the full shot，不要只写 slow。
3. 画面分区：左/中/右或前景/中景/背景，写清哪一块不许乱。
4. 一镜一次动作。焦点变化也要有起止，不要空喊浅景深。
5. **只写肯定句。** Seedance 把「不要 / 禁止 / no」当噪声，甚至反做。禁止项翻成正向替代再写：暗 → 低调光只留一盏钨丝灯；不要抖 → 机身锁死；别看镜头 → 视线停在画右门框。替换表在 `ban_dictionary`（`03-storyboard/ban_dictionary.json` 可按剧覆盖）。编译出的 motion 里不该剩一个否定词。
6. **从 0.0s 就在动。** 首帧是起点状态（可已起手），motion 第一句接着它往下做，不重新起手、不先站定。ACTION TIMING 按秒写，两拍、≤3 短句：`0.0–1.5s 手已伸向钥匙，指尖捏住；1.5–4.0s 起身收手入袖，眼先回到画右的门，头才跟过去`。第二拍带落幅和情绪尾。
7. **段首粘 `geo_layout`。** 本场的空间平面（地标、画左/画右、米数、机位在哪一侧、永不过的线、光从哪来）逐字前置，同场每镜相同，不按镜缩写。人物一句 `descriptor` 紧随其后，永不缩写。
8. **对白不进动作句。** Seedance 原声路线（`speech_mode=seedance_native`）的台词只出现在 `audio_block`：声线卡逐字 → 引号台词 + 语种 + 语气 → 只说这一句 → 不说话的人嘴闭着 → 只有环境声，无音乐，无字幕。说话时的动作和表情在紧跟的【表演】句里。

横屏都市剧禁用：环绕、闪摇、无人机、crash zoom、IMAX。这些是屋规，写在能力档 `forbidden_moves` 里给机器查，不是写进提示词的否定句；提示词里只写你要的那一种运镜。画幅默认 16:9，不要写成 9:16，除非该剧 confirm 锁了竖屏。
宫格预览只给人/导演 Agent 看整场，不拿去出视频。
