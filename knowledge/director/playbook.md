# 短打法手册

拆镜只输出，不改故事。一场先定轴和 2-3 个机位，镜头必须挂 rig_id。

1. 一镜一件可见新信息。邻镜只改一件事：机位、人物或动作。
2. 对白/心里台词镜 2-5 秒。建立/全景才可到 8 秒。禁止一句词配 8 秒冻住。秒数跟台词走。
3. 一场人物镜里 static 不得超过一半。该动就写 push/pan/track，并写速度，禁止整集都 slow。
4. 剪在动作上。上一镜带着动势出，下一镜第 0 秒已经在动作中间。禁止静接到静。
5. 第 0 秒写 start，收势写 landing。续镜 start 不是站好姿势。end_frame 是设计尾帧，不能用生成 last.jpg 冒充。
6. video_prompt 由本镜字段编译，必须含本镜 action 的英文关键词。禁止抄上一镜动作。对白不进画面词。
7. 同机位、人物有交集，出片吃上一镜真末帧。换机位仍是同一场同一轴，不准新开海报。
8. 人先审整场节奏板，再锁单镜。宫格给人看，不拿去出片。
9. 对白后必须有一眼无台词反应。每镜合同带 handle=2，给以后剪辑留手柄；assemble 这期仍全长拼接。
