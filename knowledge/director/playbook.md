# 短打法手册

拆镜只输出，不改故事。一场先定轴和 2-3 个机位，镜头必须挂 rig_id。

1. 一镜一件可见新信息。邻镜只改一件事：机位、人物或动作。禁止两个信息塞进一镜。
2. 纸面秒按桶：反应 1.2–2.0；物件插入 1.5–2.5；对白句 2.5–4.5；建立/全景 3–5；长镜头 5–8 且必须写「信息在连续时间里」。禁止一句词配 8 秒冻住。目标 14–18 镜/分（工作 16），ASL 3.3–4.3s。
3. 一场人物镜里 static 不得超过一半。该动就写 push/pan/track，并写速度，禁止整集都 slow。
4. 剪在动作上。上一镜带着动势出，下一镜第 0 秒已经在动作中间。禁止静接到静。
5. 第 0 秒写 start，收势写 landing。续镜 start 不是站好姿势。end_frame 是设计尾帧，不能用生成 last.jpg 冒充。首帧 = t=0，动作未发生。
6. video_prompt 由本镜字段编译，必须含本镜 action 的英文关键词。禁止抄上一镜动作。对白不进画面词。
7. 同机位、人物有交集，出片吃上一镜真末帧。换机位仍是同一场同一轴，不准新开海报。一镜一机位，`internal_cuts=[]`。
8. 人先审整场节奏板，再锁单镜。宫格给人看，不拿去出片。
9. 对白后必须有一眼无台词反应（1.2–2.0s）。每镜合同带 handle=2；assemble 这期仍全长拼接，要上 16–18 SPM 必须按纸面秒裁。
10. 穿过 / 笔尖 / 透身不拆。复合镜、必须单独成立的反应、物件过手、视线转换必须拆。

## 场卡先于刀

拆镜前先有场卡：这场的戏剧问题、翻转点、情绪曲线、那一颗、揭示顺序。刀法服务卡，不服务覆盖表。

- **那一颗**：场卡说的那个瞬间必须是自己单独的一镜，景别就是卡写的，是全场最紧的一颗，秒数够它慢下来。没有它，这场白拆。
- **揭示顺序**：观众先看见什么、后看见什么，逐字照卡。先局部再全身，先反应再原因，先手再脸——顺序颠倒就是另一场戏。
- **光位**：同一场主光一个方向，灯不会自己走。只有反打、越肩、反应镜可以镜像；不是反打却镜像要写动机；同场从画左直接跳画右是穿帮。
- **邻镜差**：相邻两镜在景别 / 角度 / 左右 / 运镜 / 主体里最多改两件。改三件观众断线。插入、主观、空镜不算。
- **情绪值**：每镜 0–10，峰值那镜最紧，峰值后必回中景以上。
