# 什么时候切

镜头服务节拍。信息、权力、注意力、空间理解、情绪、地点、时间——任何一个变了，开新镜；都没变，不开。
既不要一句台词一镜，也不要把一整段转折压成一张好看的大画。

一镜只装一件事：一个主动作、一个地点、最多两句对白。装不下就拆，不用摇镜糊。
**禁止**用 `internal_cuts` 在一条视频里换机位。换景别、换反应、换过手 = 开新镜。
紧景别拍脸，远处的队伍、火把、对岸交给全景或插入镜；证据（信物、伤口、空手）必须在能读清的景别里。
相邻镜追踪：左右、视线、道具、光、时间、地点。同一地点反复出现时，锚点不变。

切之前先问场卡：这一刀是不是在靠近那一颗？揭示顺序有没有被这一刀打乱？
那一颗单独给一镜，全场最紧，最慢。在它之前不要把更紧的景别用掉；在它之后至少回一次中景，让观众喘气。
同场主光不跳。反打可以镜像（画左灯变画右灯），其余镜头守住方向；换了方向要在画里看见原因（转身、开门、灯灭）。
邻镜五件事——景别、角度、左右、运镜、主体——最多改两件。想同时换三件，就是漏了一镜。

## 节奏（横屏短剧）

目标 **14–18 镜/分钟**（工作取 16），ASL **3.3–4.3 秒**。每一秒有内容。禁止把两个信息塞进一镜。

**必须拆**（一条命中就开新镜）：新信息点换了；视线转换；物件过手 / 落地 / 入袋；反应必须单独成立；对白换说话人或同一人第二句换了信息种类；观众该先看见、人物后看见。

**禁止拆**：同一动作过程的中途；穿过（肩进到肩出）；对峙留白（双方都不动，权力在持续）；笔尖悬停；透身可读。快切补在长镜头两边，不拆穿过和笔尖。

检查句：关掉对白，这 2 秒里有没有一件新的可见事？没有 → 并进上一镜或删秒。有两件 → 拆。`one_action` 里出现和/再/然后/并两个动词 → 拆。

## 纸面秒数桶

纸面 `duration_sec` 按桶写，**允许低于模型 4s**（渲染按 min，剪辑裁回纸面秒）。

| 桶 | 纸面秒 | 何时用 |
|---|---|---|
| 反应 | 1.2–2.0 | 无词、脸或眼、一件事已经发生完 |
| 物件插入 | 1.5–2.5 | 名单、工牌字、吊牌、钥匙落地 |
| 对白句 | 2.5–4.5 | 一句；第二句换信息就换镜。禁止一句配 8s |
| 建立 / 全景 | 3–5 | 一场开头地理；峰值后回中景 |
| 长镜头 | 5–8，默认封顶 8 | 穿过、对峙留白、笔尖、透身。要 >8 必须在 `shot_job` 写「信息在连续时间里：…」 |

12s 当常规 = 拆镜失败。连续两镜 ≥8s → 警告。对白后无反应、下一镜已换题目 → 警告。
