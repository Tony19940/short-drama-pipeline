# 暹粒

## 人物

| 姓名 | 身份 | 说明 |
|---|---|---|
| 速卡 | 现代柬埔寨大学生（水文与环境工程） | 本名即 Sokha。在暹粒旧河道勘测时落水穿越到古高棉。识水、算水、懂旧河床与旧闸；后被暹罗军与高棉边寨共同卷入战局。 |
| 云朗 | 高棉边寨守将 | 起初把速卡当暹罗细作，屡次绑她；从“不信水”到信人，最终与速卡联手擒暹帅。 |
| 帕东 | 老水工、守闸人 | 年轻时修过王都水渠，熟知旧河道。第 2 集与速卡一同把旧闸闸板埋装到位；第 5 集末在旧闸落斧放水。 |
| 萨里 | 王廷使者、监军 | 奉王廷之命来边寨主事。第 3 集当众以“女俘也配谈兵”踩速卡，被当场证己收束；第 5 集主张交人换平安。 |
| 沙蒙 | 暹罗统军主帅 | 率军压境、筑堰断水。第 6 集在水攻中溃败；第 7 集于水门被生擒。 |

## 分集梗概表

| 集数 | 梗概 |
|---|---|
| 第 1 集 | 速卡在暹粒旧河道勘测时落水，穿越到古高棉。高棉边寨守将云朗当她是暹罗细作，将她绑住。暹罗游骑来袭，速卡凭识水顺深漕逃生。 |
| 第 2 集 | 速卡进寨仍被绑。洪水反灌粮栈，速卡看出是旧河口淤塞所致，令众人清开旧河口；水绕旧河床而去，粮栈得救。帕东与她一同把旧闸闸板埋装到位。 |
| 第 3 集 | 王廷监军萨里赶到，当众踩速卡：“女俘也配谈兵？”速卡要求“让我看水”。她看出浅滩水下有暹罗人暗铺的筏道，斥候当场查实，萨里哑口无言。 |
| 第 4 集 | 速卡预判暹罗粮船必走深漕，云朗半信半疑。伏击得手，截下半船粮，放走另一半回去报信，寨中有人开始信她。当夜，暹罗军在上游筑堰断水。 |
| 第 5 集 | 断水第三日，正午。暹罗以“交人换平安”为名，要速卡把自己送到干河床上；实为借干河床踏寨。速卡入局为饵，安排云朗带人上坡、帕东持斧守旧闸。帕东落斧。 |
| 第 6 集 | 旧闸闸板被斧劈开，水头顺旧河床直灌暹罗象营。暹帅沙蒙正喊“人抗不过象”，象群被泥水冲乱，暹军大败。沙蒙率残部向水门退去。 |
| 第 7 集 | 速卡算准水门涨水时刻，先一步设伏。沙蒙退路被水封死、没膝难行，战象翻倒，沙蒙被生擒。此地得名“暹粒”——暹罗倒下的地方。 |
| 第 8 集 | 速卡回到现代暹粒，旧河道边仍有旧闸石槽。旅行团导游指着水说：“暹是暹罗，粒是倒下。人记不清的事，水替我们记着。”速卡俯身触水，热泪落下。 |
