# 画风 · 已锁 D 吴哥壁画

全片主风格：Angkor sandstone-relief / Khmer mural。横屏 16:9。
参考样张：02-assets/look-tests/D-angkor-relief.jpg、D2、D3。这些是选风图，不是角色 master。

画面规则：
- 线像砂岩浮雕刻痕，颜料是矿物红、金、灰绿，低饱和
- 人是高棉骨相，古铜肤，不要真人毛孔写真，也不要网红脸
- 男：sampot / chang kben，旧皮甲或青铜件，krama，凉鞋或赤脚
- 僧人：橘袍、剃发、赤脚、庄重。不是巫师，不是天主教神父
- 蒂雅：sampot，素 sbai，腰上一只小铜铃，怀里棕叶拓片。不是银舞裙
- 场：西参道木桥、东回廊砂岩。不要中国宫殿，不要泰式尖顶

运动也要像壁画在动，不要突然变成真人摄影。
禁止：旗袍、唐甲、欧洲板甲、冷白皮、字幕烧进画面。
