# 人物简介

工作轨中文，本地轨高棉名，不译成中文音译。slug 与 `CAST.md` 一致。
外形以 `LOOK-LOCK.md`、`CAST.md` 为准；剧情只取剧本和 `source/` 里写进去的，没写的不补。

每个人物一节，标题必须是 `## **slug** · 中文名 / 英文名`。编包直接读两行（本页是真源，`.pipeline/voice_cards.json` 是机器抄本），格式不要改：

- `- **外形卡**：` 一句 `descriptor`，5.2 逐字贴进每条提示词并后接「100% 以参考图为准」。体型 / 发型 / 当前服装状态 / 动作相关手部道具。**不写年龄**，不写情绪。换装变体写成子项 `  - <costume_state>: …` 或另起一行 `- **外形卡（<costume_state>）**：…`。
- `- **外观年龄段**：` 只用于生成主图（如“二十出头的大学生”“四十岁上下”），不贴进 5.2 外形卡。外形卡不写年龄，主图提示词却必须写外观年龄，否则模型会按画风默认年龄画（012 的学生被画成了中年人）。
- `- **声音卡**：` 1–2 句 `voice_card`，有台词才写（只在电话里、画外出声的人也写），逐字进 `audio_block`。音高 / 音色 / 节奏 / 口音 / 说话时的身体习惯。不写情绪词，不写年龄，不写句子长短（"短句"会让每句台词都被砍短）。格式见 `knowledge/sound/vo.md`。
- `- **说话方式**：` 有台词才写，台词关交给 Gemini 写高棉语用：这个人怎么称呼别人、对上对下怎么用词（语体）、口头禅、会不会重复、会不会打断别人。声音卡管嗓子，这一行管用词。不要写"句子短""两三个字一句"：人物的区别在怎么说，不在说多短。称呼见 `CULTURE.md`「说话」。
- `- **高棉名**：` 名字的高棉文写法，高棉语台词和字幕一律用它。
