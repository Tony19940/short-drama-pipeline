# 文化锁 · 全 100 集（神话童书轨）

状态：locked。生成任何一张图之前先核这一页。  
**金边都市短剧、全仓库禁止清单和检查表以根目录 [`CULTURE.md`](../../CULTURE.md) 为准。** 本页只补童书神话细节。

观众是柬埔寨孩子和家长。画错服饰、建筑、神话，会被认成「把高棉画成泰国 / 印度 / 迪士尼」，这是真冒犯，不是审美问题。

泰柬近年仍在争 sbai、宫廷舞、服饰归属。宁可少装饰，不要画成泰国古装。

## 总原则

1. **用柬埔寨人自己讲的版本。** 开国用婚礼版普拉通与娜娘，不用印度侨陈如译文腔；罗摩用 Reamker，不用宝莱坞 Ramayana。
2. **先核再画。** 新角色、新建筑、新神兽，先查高棉出处（吴哥浮雕、宫廷舞、婚礼、民间年画），再写进角色卡，再生图。
3. **神圣的东西不拿来搞笑。** 龙王、佛、僧、吴哥、阿普萨拉、王桥七头蛇，可以温和、可以给孩子看，不能丑化、不能恶搞、不能当怪物打。
4. **一张图只属于高棉。** 不要泰式屋顶尖饰、纱丽、中国龙、西方美人鱼、韩系网红脸。

## 人

- 成年或明确的故事书儿童。橄榄到古铜肤，颧骨开阔，下颌偏圆，鼻梁中等，眼睛偏圆，乌黑直发。
- 不要冷白皮、欧式五官、韩系磨皮、北印度纱丽脸、日本动漫尖脸。

## 衣

只许用高棉形制，名称也用高棉叫法：

| 用 | 不要 |
|---|---|
| 男：សំពត់ / សំពត់ចងក្បិន sampot、chang kben（从腿间穿过再掖腰，像宽松裹裤） | 泰式 chong kraben 的现代舞台剪裁、纱笼乱裹 |
| 女：sampot + ស្បៃ **sbai**（从左肩垂下的长披肩） | 印度纱丽、泰式 sabai 舞台装、露脐莱茵石 |
| 宫里：金腰带、项圈、臂环、吴哥式宝冠 mokot / kbang | 泰式尖塔 chada 堆满、中国凤冠 |
| 百姓：粗布 sampot、ក្រម៉ា krama 格纹 | 牛仔裤、汉服、和服 |

**本集关键：** 娜娘的金 sbai 就是龙尾在人间的形状。新郎提起 sbai，演的是普拉通跟着她回家。这条布必须像布，不要画成鱼鳍。

儿童简化：可以少一层金饰，轮廓仍要是 sampot + sbai，不要改成连衣裙。

## 龙 / នាគ naga

高棉的龙是**水里的蛇神**，是祖先，不是妖怪。

| 对 | 错 |
|---|---|
| 长蛇身、鳞、常是 **七头眼镜蛇冠**（吴哥桥栏杆） | 西方喷火龙、中国长须龙 |
| 娜娘在岸上是**人**，龙的提示在鳞纹镯、琥珀眼、sbai | **美人鱼鱼尾**（迪士尼） |
| 龙王庄严、慈祥，可略大，仍是蛇神或人首蛇身 | 肥胖婴儿、滑稽喝水小丑 |
| 颜色：绿金、琉璃，像吴哥石上的蛇 | 荧光粉鱼鳞、贝壳胸甲 |

西哈努克城海边的《普拉通与娜娘》铜像：两人都是人形宫廷装，他在她身后执 sbai。这是当代柬埔寨的官方形象，本系列岸上戏跟它走。

## 建筑

- 吴哥：莲花塔、回廊、七头蛇栏杆、浮雕阿普萨拉、红色砂岩或灰色砂石。
- 村寺：黄墙、赤陶瓦、糖棕院子，不是泰式飞檐 chofah 密密一层。
- 龙宫：水下廊柱，绿金，仍是高棉柱头，不是希腊神殿，不是龙宫卡通贝壳。

## 神与故事

- 阿普萨拉：吴哥舞姿、sampot tep apsara、指尖后折，不是芭蕾，不是天女散花仙侠。
- Reamker 的哈奴曼、金鱼公主：用高棉舞剧扮相，不要印度年画神猴。
- 僧人、佛像、寺院：庄重。孩子故事里可以温和，不许拿来出洋相。
- 节庆：宋干、亡人节、送水，按柬埔寨自己的仪式，不把泰国泼水节服装套过来。
