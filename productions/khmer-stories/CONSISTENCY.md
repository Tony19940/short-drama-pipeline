# 角色与场景一致性

状态：locked。跨集故事（普拉通 01–03、兔子 13–32、Reamker 47–62）全靠这一页，不靠模型记忆。

模型没有「同一张脸」的记忆。每次全新生成都会换脸、换身高、换房子。一致性是造出来的：先锁主图，以后只改、不另开。

## 一、第 01 集男主偏矮：原因

不是故事设定他矮，是主图工序错了。

1. **两张主图分开 `image_gen`。** 王子提示词偏「儿童贴纸」，头大、腿短、五头身。娜娘提示词写成「年轻女人」，头小、腿长、七头身。
2. **没有身高图。** 两人从未在同一张图里按比例站过。合成时模型把两张贴纸原样贴上，矮的还是矮。
3. **合成只改情节，不改尺度。** `image_edit` 会尽量保住参考图里的身体比例，所以 10 镜一直矮下去。

西哈努克城铜像和婚礼仪式里，普拉通是成年新郎，应与娜娘同龄、略高或等高，不该是小孩配大人。

## 二、以后怎么避免（身高）

每个会并肩出场的组合，先出一张 **身高图**，再拆单人主图。

| 组合 | 身高锁（脚到头顶，不含高冠） |
|---|---|
| 普拉通 : 娜娘 | **1.05 : 1**（他略高半头，最多等高） |
| 龙王 : 两人 | 蛇身立起约为两人的 1.4–1.6 倍，庄严，不压成巨人 |
| 同季固定搭档 | 角色卡里写死「头数」和相对身高 |

做法：

1. 先 `image_gen` **一张**两人并立、脚在同一地平线的身高图。
2. 量过再拆：从身高图 `image_edit` 出单人主图，禁止再对同一人全新生成。
3. 每张双人镜头必须引用身高图 + 两人主图，提示词写死：「same height relationship as the scale sheet, his crown may be taller, his body is not a child next to an adult。」
4. 出图后看脚和眼睛：脚齐地平线，他的眼睛不低于她的眼睛。不合格作废。

不要用「可爱小孩王子」提示词。儿童向是圆脸红晕，**年龄仍是适婚青年**。

## 三、跨很多集：人怎么不变

以 **季** 为单位锁资产，不按集重做脸。

```
shared/characters/<slug>/
  scale.jpg          与固定搭档的身高图（只此一次全新）
  master.jpg         全身主图（从身高图改）
  face.jpg           脸锁
  variants/          换装、湿身、戴冠……全从 master 改
```

规则：

1. 一个 slug 全季只有一次 `image_gen`（身高图或单身主图）。
2. 第 2 集及以后：只 `image_edit` 主图。提示词复述固定锚点（脸、发、衣服颜色、sbai 纹样、身高比）。
3. 换装写在变体表，不另开一张新脸。
4. 跨季同一人（如 01 与 94 的普拉通）：仍用季 1 主图，只改年纪/光线，不换骨相。
5. 兔子 20 集、Reamker 16 集：开季当天把身高图 + 全身 + 脸锁过审，中途不许换主图。

## 四、跨很多集：地怎么不变

场景同样只锁一次。

```
shared/scenes/<slug>/
  master.jpg         空镜主图（无角色）
  eye-level.jpg      若主图是俯视，先改出平视再放人
```

规则：

1. 沙洲、龙宫、新陆地、王宫、井、林：各一张 master。
2. 人进景：场景 master + 角色 master 一起 `image_edit`，只改「人在哪、在做什么」。
3. 同一地点换集：还是那张 master。变的是时间（黄昏/夜）或道具，写成变体，不换地形、树位、岸线。
4. 邻镜差分：从上一镜改，不从空白再生成一场「差不多的海」。
